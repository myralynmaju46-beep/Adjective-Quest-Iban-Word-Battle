# Adjective Quest — Iban Word Battle

Live demo: https://myralynmaju46-beep.github.io/Adjective-Quest-Iban-Word-Battle/

Ringkasan:

- Projek permainan web statik (HTML / CSS / JS).

Jalankan secara tempatan:

- Buka `index.html` dalam pelayar.
- Atau jalankan server ringkas (Python):

```bash
python -m http.server 8000
# kemudian buka http://localhost:8000
```

Kemas kini & publish:

- Buat perubahan, commit, dan push ke GitHub.
- GitHub Pages diaktifkan untuk branch `gh-pages` pada repo ini.

Nota domain:

- Untuk domain custom, tambah fail `CNAME` di root dengan nama domain anda dan tetapkan DNS seperti yang diperlukan oleh GitHub Pages.

Terima kasih!
